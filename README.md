Proyecto para una calculadora Clase DevOps 2026-2

git init: Sirve para crear un repositorio nuevo, lo inicializa 

git add: Agrega o prepara los archivos que son modificados para incluirlos y subir los cambios.

git commit: Sirve para guardar los cambios de forma definitiva con una descripcion que explica que clase
de cambios se hicieron.

git push: Sube todos los cambios, los envia todos los cambios guardados de manera a local al repositorio remoto
en github.

git status: Muestra el estado actual de un archivo y tambien si esta listo para subirse.

git diff: Especifica los cambios exactos que se hicieron en un archivo.

git log: Nos muestra el historial del proyecto con los commits que se han hecho, quien los hizo, fecha en la que se hizo y demas.
